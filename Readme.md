## Features
___
### Backend
- Java JDK 25
- Spring boot
- Build system: Maven
- Lombok
- OAuth2 for login authentication
___
### Database
- PostgreSQL (Aiven)
___
### Backend testing
- Framework: JUnit
- Additional libraries: AssertJ
- Test DB: h2 embedded database
___
### Frontend
- React
- Typescript
- Vite
- React Hook Form for input validation
___
### Other features
- GitHub CI for backend
- SonarQube for clean code verification
___
